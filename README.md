# NEET 2027 Study Studio

A static study site for NEET UG 2027 preparation: unit-by-unit study map, formula and trick sheets, flash cards, past-paper practice, a focus timer, mock tests and progress tracking. Progress is saved in the browser only.

Past-paper questions are tagged to the 50 official NMC 2026 syllabus units. Written solutions and the original paper PDFs belong to their publishers and are not included here.

Run locally: `python3 -m http.server 8000` and open http://localhost:8000
